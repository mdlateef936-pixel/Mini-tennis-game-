# Mini Tennis Game

A beginner-friendly tennis/Pong-style game made with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and scoreboard
- `style.css` — design and layout
- `script.js` — ball movement, paddles, computer opponent, scoring and messages

## How to run
1. Download or extract this folder.
2. Open `index.html` in a web browser.
3. Click **Start Game**.
4. Move the user paddle with the **Left / Right arrow keys** or **A / D**.
5. First to 5 points wins. Use Pause and Reset when needed.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `mini-tennis-game`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's main/root folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your game link will appear in the Pages section.
